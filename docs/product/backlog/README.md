# Backlog / Work Items

Work items follow the template in `project-process-framework/templates/work-item-template.md` (separate repo). This folder holds them as markdown while the project is pre-Issue; each item is written to be copy-pasted directly into a GitHub Issue and added to the repo's Projects board when picked up — same pattern as `docs/governance/open-items-register.md`, but for planned work rather than deferred concerns.

**Start here:** `MASTER-BACKLOG-OUTLINE.md` — the full list of epics and high-level work items across every hat, titles only (detail added when an item is actually picked up). Two items are fully detailed now as validation examples of the template shape:

- `EPIC-CACHING.md` + `WI-CACHE-001.md` — Interface/Contract type, derived from ADR-0002
- `WI-NFR-001.md` — Document/Artifact type, derived from ADR-0002/0004/0005/0006 + vision

`PARKING-LOT.md` — transient, per-conversation open items not tied to a specific work item. Distinct from `docs/governance/open-items-register.md` (permanent tech debt/tradeoffs).

Once epics are picked up one at a time, their remaining work items get fully detailed here, following the same pattern.
