## Threads

- **Entry path:** APIM in front of three frontends (0008, 2026-09-06) became a BFF in front of the browser with APIM kept in front of service APIs (0013, 2026-10-26). Services still validate every token themselves.
- **Identity:** B2C to Entra (2026-09-11); a local mock issuer with browser login (2026-09-13); service callers added with client credentials (0018, 2026-10-28); the DEV credential type is still open.
- **Frontend:** SPA (2026-09-13) replaced after six weeks by server-rendered Next.js (2026-10-26), with the older record kept.
- **Caching:** one server cache (0002) became three owned layers (0014); only the server-side library is built.

Three things the phases show. The foundational build was delegated and the slice was interactive, and the controls grew between them (the handoff rules in September, the approval list and clean-agent checks in October). The plan's order held until a real run contradicted it (the issuer, the service mapping, the cold-start timing). And the plan's phase 4 and 5 items were done in the margins of the slice, not as phases, which is why the project plan reports several phases as partly done.
