## How to read the numbers

- **The screen's line count includes documents.** Most of the added lines are corrections to documentation and the records of the review, not code.
- **One long context.** The usage screen attributed 94% of the last day's use to continuing in one context across different tasks (the document pass, two review rounds and three fixes), and advised starting fresh when the task changes. The next session starts from the saved resume list instead.
- **No test report was made.** The full .NET test report is still to be produced; the figures include no cost for it.
- **No claim is made about value per unit of cost.** The human review time is not in these figures.
