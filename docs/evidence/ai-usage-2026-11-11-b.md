## What the session did

Chaos specs per scenario, all committed on the branch and not pushed. The runner `scripts/ci/chaos-smoke.mjs`, the new scenario `lost-confirmation`, and specs for `checkout-trouble`, `lost-confirmation`, `flaky-broker` and `broker-outage`, each run on the whole stack. They found three defects that were fixed (register 179 a same-key retry could not recover after a failed checkout, 180 stock given back for an order that stood, 181 the runner's logs cut at 64 KB) and two that are open for a decision (182 a broker outage parks healthy orders' outboxes, 183 dead-lettered notifications); register 171 was measured for the first time. A baseline run with no scenario (62 of 62) and a seed knock-on fix in a Playwright spec came first; register 178 records the rule that tests must not break when data or tests are added. The notification service was added to the runner as an opt-in. 5 commits.

## How to read the numbers

- **Relative cost is a size, not a price.** 2.12 means a little over twice the base session, and says nothing about money.
- **The screen's line count is not the repository's.** It also counts edit scripts and scratch files.
- **No claim is made about value per unit of cost.** The human review time is not in these figures.
- **A caveat from the screen itself.** It attributed 78% of the last day's use to continuing in one context across different tasks, and 24% to the size of the context.
