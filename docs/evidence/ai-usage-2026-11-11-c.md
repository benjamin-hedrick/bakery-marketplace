## What the session did

The chaos work was taken from its open items to done, all committed on the branch (14 commits including the two that record this usage and the regenerated traceability table) and then pushed on the lead's instruction (the usage record was corrected afterwards from a fuller screen, in a commit not yet pushed when this was written). Three defects the whole-stack runs had found were fixed: register 182 (a broker outage no longer parks healthy outboxes: a typed transport exception, retry with back-off), 183 (notification redelivery backs off and allows ten deliveries) and 171 (a payment is idempotent on the order id with an idempotent void, a notification is claimed before it is sent and the sender is idempotent on the event id; this added `SetIfAbsentAsync` to the shared cache interface with contract tests). Specs for `bff-door`, `web-door`, `slow-cache` and a new `stale-cache` were written and run on the whole stack, with a new delete-only cache fault (`deleteFailureRate`); the four older scenarios were re-run on the final code, flows 07 and 11 were run on the emulator (both passed), ADR-0024 was accepted and ADR-0002 amended, and the evidence is in `docs/evidence/WI-CHAOS-003/`. The stale-cache run found that failed deletes open the cache's circuit breaker and that a successful delete left a stale fallback copy (fixed); the remaining flap within the TTL is register 184, documented and not changed. The lead also asked, outside the repository, for resume wording based on the repository's real examples.

## Errors the assistant made, and what caught them

- A spec that passed without proving anything (twice: the stale-cache first run saw no stale sample, the web-door browser check saw too few faulted answers): caught by asserting that the fault's effect was seen, and by reading the logs and probing Redis directly.
- A runner that judged a run by the last run's leftover figures after a spec failed early: caught by the false "30 notifications missing" it printed; the runner now clears old figures.
- Raising the redelivery back-off made `flaky-broker` too slow: caught by the whole-stack run; the back-off was capped.
- Shell heredocs and backticks in double-quoted strings, against the rule in `CLAUDE.md`: one failed to run and one ran a backtick as a command and dropped a file name from a link; caught by the output and the link check. Edit scripts written to files were used from then on.

## How to read the numbers

- **Relative cost is a size, not a price.** 6.32 means a little over three times the base session, and says nothing about money.
- **The screen's line count is not the repository's.** It also counts edit scripts and scratch files (a probe script and an edit script were written outside the repository).
- **No claim is made about value per unit of cost.** The human review time is not in these figures.
- **A caveat from the screen itself.** It attributed 86% of the last day's use to continuing in one context across different tasks, and 20% to the size of the context.
