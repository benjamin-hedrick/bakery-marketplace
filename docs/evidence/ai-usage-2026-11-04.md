## What the sessions did

**Session G:** the notification service running in Compose with a real-checkout run, the event-name contract test and tracing (`NOT-001`); the customer order history (`WI-CUST-007`); the personalization scoping with the lead, ADR-0022 (tags) and the specs (`EPIC-TAGS`, `TAG-001` to `TAG-005`, `PREF-001`, `SRCH-001`, `CUST-005`, `CUST-006`, `CUST-008`, `ORD-009`, `QUE-005`); `TAG-001`, `PREF-001` and `SRCH-001` built; the notifications pull request merged and the branches rebased and pushed.

**Session H:** the personalization pull request merged; ADR-0022 accepted and amended with the diet composition rule; eight work items built and gated on one branch (`CUST-005`, `CUST-006`, `ORD-009`, `QUE-005`, `CUST-008`, `TAG-002`, `TAG-003`, `TAG-004`, 11 commits); register items 140 to 143; two whitespace fixes found by the formatter; two real-stack runs lost to memory and to a kept stack's state before a clean run of 55 of 55 journeys; the smoke run now raises the web login rate limit for itself only.

## How to read the numbers

- **Session H's figures were read before the final rebase and the secret scan**, so they understate it slightly.
- **Lines added is not a quality or productivity measure.** It counts tests, documentation and evidence as well as code, and generated documents (the status and traceability tables) are rewritten many times in a session.
- **Cost per work item is not a useful figure here.** The items differ greatly in size, and a large share of the cost is the cache read that comes with a long session, not the number of items.
- **No claim is made about value per dollar.** Two sessions are not a sample, and the human review time is not in these figures.

## Observations that bear on how to use the tool (for the AI collaboration record)

These are the session's own notes on where effort went, not measurements.

- **Failures that cost time were mostly mechanical:** shell commands with many quotes that did not parse (several scripts had to be written to a file and run), edit scripts whose text anchors no longer matched after the formatter had reflowed a file, and a test locator that matched the label itself instead of something inside it. A habit of writing scripts to files first removed most of them.
- **Mutation checks earned their cost:** breaking a safety property on purpose (the acknowledgement rule, the window check, the platform tags, the "all of" filter) found one assertion that could pass for the wrong reason and confirmed the rest.
- **The real-stack run found things the mock-backed suite could not:** the seed's real option names, stock used up by repeated runs, and the web app's login rate limit. It also needed a clean stack: a stack kept for investigation gave misleading failures.
- **A decision asked early saved a rebuild:** the diet rule and the scope of "prefer" were put to the lead as two questions with a recommendation each before any code was written.

## What this does not show

The human decisions in the sessions (the allergens and their labels, the caps being adjustable, the cart acknowledgement blocking with an override, how long order allergens are kept, the diet rule); the review of the work that is still to come, because the lead has not yet reviewed this branch.
