## How to read the numbers

- **The figures are as of the middle of the session.** The screen was read before the final commits and the plan update, so the totals understate the session slightly. The record is kept because it is the figure the lead pasted.
- **Lines added is not a quality or productivity measure.** It counts tests, documentation and evidence as well as code. The screen reports 0 lines removed, which is not explained here.
- **No claim is made about value per dollar.** One session is not a sample, and the human review time is not in these figures.
