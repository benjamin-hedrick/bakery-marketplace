## What the session did

Register 201's first point was closed: the Android build now stops its Gradle daemon. Register 203 gave the catalog's listing outbox counters for failed and parked publishes and a runbook, run on the local stack. Register 166 stopped each dependency under load on the local stack (the identity issuer, the cache Redis, the Cosmos emulator) and recorded what the customer saw; it opened three items, all fixed the same session with the lead's approval. Register 204: the mock issuer keeps one signing key across restarts, from the git-ignored `.env`. Register 205: a cache outage now fails fast instead of stalling about 5 s, and the circuit breaker logs its state changes instead of a warning per call. Register 206: the catalog answers an unreachable store with 503, and a Cosmos read gives up after 3 s instead of about 13 (reads only, the lead's choice). Each fix was run again with the dependency stopped. Register 207, an intermittent chaos test seen in the Linux check, was fixed at the site that failed and then, on the lead's word, at the three other places with the same ordering.

## Errors the assistant made, and what caught them

Register 201 holds them in full, (1) to (9) of the second session. In short:

- The first cache outage run had no pacing, so the BFF's rate limit refused most calls and that half measured nothing; it was run again paced.
- The first read limit for register 206 trusted the Cosmos SDK to honour cancellation, which it does not while it initializes; the tests ran into their guard, and the wait itself was then bounded.
- A mutation check did not compile, which first looked like a hung test; a long probe was piped to `tail`, hiding its progress.
- A commit moved a line of the register from one item to another; found later and put back.
- Edit scripts and a commit message were written through heredocs, against the repository's rule.

## How to read the numbers

- **Relative cost is a size, not a price.** 14.44 is about fourteen times the base session: three live outage runs and their reruns, code changes in four shared libraries and two services, and several full Linux checks.
- **The conversation was compacted once**, which is the expected rebuild above; nothing was lost to an idle cache.
- **Most of the wall time was the stack runs, the outage runs and the gate runs**; the screen counts the assistant's time only.
- **No claim is made about value per unit of cost.** The human review time is not in these figures.
