## What the session did

The lead asked what it would take to deploy the dev environment to Azure, test it and tear it down, and chose the pipeline route (ADR-0020 as designed), keeping the foundation after teardown. The session installed the Azure CLI and Terraform, checked the bootstrap runbook's commands against the CLI's help, and ran the bootstrap from the lead's signed-in CLI: the resource providers registered, the Terraform state account with no shared key access, versioning, soft delete and a delete lock, the empty dev resource group, and the two pipeline identities' roles (the lead created the service connections in Azure DevOps and approved the role changes, including the constrained role-assignment right). Checks 1 to 5 passed, the last a plan of the foundation against the remote state (nothing applied). The record (`docs/evidence/WI-DEP-001/bootstrap-2026-11-19.md`), the runbook corrections and registers 106, 108 and 213 were committed locally; nothing was pushed. The applies are for the next session.

## Errors the assistant made, and what caught them

Register 201, (15) to (17): Terraform was first run from Windows PowerShell, which split an argument at its dot; a lookup took the service connection ids the lead pasted for application ids; and the first gate run failed on a link to an evidence file not yet added to git. Each cost one command and was caught by the command's own error.
