## What the session did

The branch was rebased on `main` after `feature/register-hardening` merged, and the gates the previous session had skipped were run: the Node gates (which caught the register 200 commit's stale generated pages), the secret scan, the web skeleton smoke against the new seed, and the Linux check, where three tests that slept on the real clock failed once and passed on a rerun (register 202). At the lead's choice the three were moved to a manual clock, and the chaos runtime now takes the host's clock. Register 74 was finished: counters for failed publishes and parked orders, and a runbook for a parked order outbox, run on the local stack (parked, found, unparked without a fix and parked again, fixed). Register 66 was finished locally: every listing carries its kind and every listing read checks it, and the catalog container's time to live was checked on a fresh stack. Register 162's Android part needed nothing (the only finding left is register 199). Register 203 records the catalog listing outbox's missing counters and runbook. All gates passed on the final tree; nothing was pushed, at the lead's choice.

## Errors the assistant made, and what caught them

- It named the merged pull request by a number it had not checked, and first wrote the merge date from the system date instead of the commit. Noticed by the assistant before commit.
- It wrote an edit script through a heredoc, against the repository's rule. Noticed by the assistant; later scripts were written as files.
- A throwaway database probe had two bugs (a cross-partition query the emulator did not evaluate, a date read wrongly), costing a few retries during the live run.
- Two misses reached commits and were caught by the final gate run: a whitespace error (the format check had run before the last edit) and a stale traceability table (checked before the new evidence file was added to git). Both were folded back before anything was pushed; register 201 records them.

## How to read the numbers

- **Relative cost is a size, not a price.** 5.60 is between five and six times the base session: three code changes, two live runs and four full gate passes.
- **Most of the wall time was the gate runs and the live reproduction** (the relay's back-off made each parking take minutes); the screen counts the assistant's time only.
- **No claim is made about value per unit of cost.** The human review time is not in these figures.
