## What the session did

- **Build 88, the first complete dev deploy:** read from the run's timeline and step logs through the Azure DevOps CLI (set up this session; the artifacts could not be downloaded with the lead's sign-in). Evidence file, register 227 resolved, cost read (about 0.15 USD so far).
- **From the lead's machine:** the deployed suite cold and warm, latency, and the cold starts. The lead kept scale to zero and asked for the cold starts to be measured: the warm-up script, run as the suite's global setup, and the observe step's replica-start query (register 228).
- **The UAT proposal (`WI-DEP-002`)** with every decision taken: what of ADR-0020's design was in the code and what was not, a second Cosmos account for UAT, run options as pipeline inputs, and the subscription's one-environment-per-region quota (UAT in East US 2).
- **Both refactors, approved:** the dev resources in a shared module with `moved` blocks (a read-only plan against the live dev state showed only moves; `plan-summary.mjs` fixed, or the first run would have failed its plan stage), and the pipeline's stages in a shared template (byte-for-byte equivalent after substitution; Azure DevOps' own preview matched `main`'s expansion).
- **Dev chaos (`WI-CHAOS-006`), the plan agreed as a whole, then built:** the C# library applies `where`, `off` and `signals` with shared vectors; the doors are aimed; the BFF passes a service's faults on; chaos seed data; `dev-chaos.json`; four chaos-aware tests; the dev-only `chaosScenario` input. On the whole local stack: the chaos tests and the regular suite pass together in parallel with the scenario on, and the chaos tests pass on the plain path without it.
- **Cleaned up** 2.25 GB of nested `.terraform` copies left by an earlier workaround (register 201 (32)).

## Errors the assistant made, and what caught them

- **Process (register 201 (33) to (35)):** files and commit messages written through bash heredocs, against CLAUDE.md's shell rule; three escaping mistakes in edit scripts (a `String.replace` with `$'` that pasted the rest of a test file into itself, restored from git; twice `\n` landing as real line breaks), each caught by the formatter or the tests; a commit message that overstated a gate count, corrected before any push.
- **A subscription id typed from memory, wrong,** in a one-off plan script; replaced with a read from the sign-in before the script ran.
- **A mangled path for a saved plan file;** Terraform refused to write it, and a search confirmed nothing was left behind.
- **Four inaccurate sentences in documents, caught on rereading before commit:** an approval environment's name (`dev-apps` for `dev-app`), cold-start times stated as 15 to 26 seconds instead of 20 to 26, a README line that merged two runs into one, and an evidence line saying a file's header was unchanged when one paragraph had been updated.
- **A test selector** that looked for the wrong alert; the system had behaved correctly, and the first local run showed it.
- **A first reading of the Azure DevOps CLI's errors** as anonymous access to the project; checked (the project is private and the CLI uses the lead's sign-in) before anything was reported.

## How to read the numbers

- **Relative cost is a size, not a price.** 21.75 is among the larger sessions: two refactors proved against a live environment, a cross-language change to the chaos libraries, and two full local stack runs.
- **Most of the elapsed time was runs** (the deployed suite against Azure, the gates, the Terraform checks, the local stack); the screen's API time counts the assistant only.
- **No claim is made about value per unit of cost.** The human review time is not in these figures.
