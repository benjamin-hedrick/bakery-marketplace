## How to read the numbers

- **Cache reads dominate the token counts** because each request resends the whole conversation, served from the prompt cache. The cost is driven mainly by output tokens and cache writes, not by the 52.7M and 12.8M cache-read figures.
- **Lines added is not a quality or productivity measure.** It counts documentation, tests and generated lock files as well as code. It is shown only because the screen reports it.
- **No claim is made about value per unit of cost.** Two sessions are not a sample, the work differs, and the human review time is not in these figures.

## What this does not show
