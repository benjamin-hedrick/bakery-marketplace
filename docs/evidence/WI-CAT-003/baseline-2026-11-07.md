> **Status:** Snapshot · 2026-11-07

**Current result:** passed (no failed request). This is the "before" measurement that `WI-CAT-003` requires; the three-run comparison with and without the cache, taken after the cache was built, is `after-2026-11-07.md`.

- **Commit:** `ea25d75` on `feature/mobile-session-tests` (no listing cache built yet; the catalog reads Cosmos on every browse).
- **Command:** `node scripts/dev/demo.mjs --stop-after 240`, then `node scripts/dev/measure-latency.mjs --reads 50 --orders 20 --json latency-before-cat003.json`.
- **Stack:** the local demo stack on one Windows 11 machine: host processes for the catalog, ordering, BFF and web app, Docker for Redis, the Cosmos emulator and the mock issuer. The seeded catalog is small, so browse reads few listings per vendor: a larger catalog would show more of the cache's effect.
